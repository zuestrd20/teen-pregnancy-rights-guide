# 先懂，再選擇｜台灣青少年懷孕與權益

繁體中文學生教育網站，使用公開彙總資料及虛構匿名情境。提供2016–2025官方15–19歲女性生育率、法律與受教權、性健康、求助資源與互動學習。

## 指標的重要限制

生育率不是懷孕率，15–19歲不是未滿18歲。本次沒有取得可核實、定義一致的全國未滿18歲懷孕比例十年完整序列。圖表保留內政部原表整數精度，沒有補造小數或缺值。

- 統計依據：`STATISTICS_SOURCES.md`
- 法律與健康來源：`LESSON_SOURCES.md`
- 資料下載：`data/birth-rate-2016-2025.csv` 與 `.json`
- 查核日期：2026-10-05

## 使用與維護

純靜態HTML/CSS/JavaScript，不依賴外部套件、API或字型。GitHub Pages從main分支根目錄發布。直接開啟index.html亦可使用。圖表有文字描述與完整表格；JavaScript停用時核心內容仍可閱讀。

網站不設帳號、不蒐集姓名、年齡、懷孕或健康資料，沒有追蹤分析及持久化儲存。情境回答只留在當次頁面記憶體。

教育資料不能取代個別醫療或法律服務。法令、服務時間及資源請以主管機關及專業評估為準。
